# 🔤 쉬운 영어 번역기 (Easy English Translator)

초보자를 위한 **쉬운 영어/쉬운 한국어 번역** 및 **한글 발음 독음(한국어 발음)** 제공 웹 애플리케이션입니다.

---

## ✨ 주요 기능

1. **한국어 → 쉬운 영어 번역**
   - 직관적이고 쉬운 기초 일상 영어로 번역
   - 번역된 영어 문장 바로 밑에 **한글 발음(독음)** 자동 생성 (예: `Where is the bathroom?` → `웨어 이즈 더 배쓰룸?`)
2. **영어 → 쉬운 한국어 번역**
   - 어색한 직역 대신 자연스럽고 이해하기 쉬운 한국어 구어체로 번역
3. **음성 지원 (Web Speech API)**
   - **발음 듣기 (TTS)**: 보통 속도(1.0x) 및 천천히 듣기(0.7x) 지원
   - **마이크 음성 입력 (STT)**: 마이크로 말해서 바로 번역
4. **상황별 실생활 표현집**
   - 기본 인사, 식당 & 카페, 쇼핑 & 계산, 길찾기 & 교통, 호텔 & 숙소, 긴급 상황 카드 모음
5. **나만의 문장장 (즐겨찾기)**
   - 자주 쓰는 문장을 브라우저에 저장하고 언제든 다시 확인 및 발음 듣기 가능

---

## 🚀 실행 방법

### 방법 1. 원클릭 실행 (추천)
폴더에 있는 **`start.bat`** 파일을 더블 클릭하면 자동으로 로컬 서버가 켜지고 웹 브라우저가 열립니다.

### 방법 2. 직접 브라우저로 열기
**`index.html`** 파일을 더블 클릭하여 크롬(Chrome), 엣지(Edge), 사파리(Safari) 등의 브라우저에서 바로 열 수 있습니다.

---

## 📁 파일 구성

- `index.html`: 메인 웹 애플리케이션 UI
- `style.css`: 모던 반응형 스타일시트
- `phonetic.js`: 영어-한글 발음(파닉스 및 사전) 변환 엔진
- `translator.js`: 쉬운 영어/한국어 번역 및 후처리 엔진
- `presets.js`: 상황별 유용한 필수 표현 데이터
- `app.js`: 전체 이벤트 핸들러 및 음성/저장소 로직
- `server.py`: 로컬 경량 웹서버
- `start.bat`: 원클릭 실행 배치 파일
